# 市场与政策

`records.json` 保存审核后的文字记录，RTD 构建时生成 `/market/policy.html`。
页面按「政策变化／需求变化 → 原理解释 → 产品影响」列表呈现，可按国家、状态和标签筛选。

本次包含十二条记录。欧规语言要求为全部在售产品的电子说明书扩展至十二语；纸质版保留英、法、西、德、意五语基线，并按项目和批次增补。原始资料截图不进入发布快照。

在 `Hello-Docs` 内容分支更新文字和参考链接，通过仅包含 `docs/knowledge/**` 的内容 PR 合入。
构建代码和页面模板在 `auto-manual` 维护；飞书多维表到此快照的自动同步尚未启用。

验证时使用当前工程镜像的 `tools.rtd.market_policy.market_context` 读取快照，再从现有 `docs/publish/web` 执行 Sphinx 构建。检查十二条记录、筛选、窄屏显示，以及知识页到说明书的跳转。
