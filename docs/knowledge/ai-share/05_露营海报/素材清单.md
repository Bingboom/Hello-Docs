## 真实截图与说明性图片

- “配图”中的 HTML 工作台、改价海报、钉钉表格和 MCP 回读图片保留原始实录，不用生成图片代替操作证据。
- “工作台使用说明-实录.png”记录的是制作当时的说明页面。当前下载包调整过目录与跨平台启动方式，实际操作以文字版使用说明和包内 README 为准。
- Q 版流程图是说明性示意，不是操作截图。产品插画为生成素材，原始来源见 [插画制作记录](assets/provenance.json)。
- 版本号随测试次数累计，不要求读者复现相同编号。静态截图不会随本地试用自动更新。
- 现有记录缺少的证据不补画，也不挪用另一套实现的报告。

## 分享边界

当前分享稿、完整练习、工作台说明、核验记录和现场脚本相互对应。离线发送网页材料时须保留相对目录结构；单独的工作台 ZIP 只包含运行工具所需内容。

公开素材只放教学数据与已授权的教学表链接；不放上传凭证和私有绑定。网页发布、附件上传、持续云端更新是不同事情。这里有本地制作与一次上传记录，钉钉持续自动更新仍未接入。
