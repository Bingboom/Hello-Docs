跟着做一次：学生情况卡

假设你是一位班主任，要给全班 45 个学生准备家长会材料。成绩、课堂表现和家访记录散在几份文件里，需要逐个找资料、算成绩变化，再复制到文档里排版。

可以让 Agent 帮忙写一个程序，按学生汇总资料、计算变化，生成每人一页的情况卡。下次资料更新，换上新资料，就能重新生成。

这次先用 3 个虚构学生的资料，姓名、成绩和记录都用于演示。

在一个空文件夹里开始

用已经安装并登录的 Codex 或 Claude Code，选其中一个就行。

  1. 在电脑上新建一个空文件夹，叫 student-report。
  2. 在 Codex 或 Claude Code 中打开这个文件夹。
  3. 把下面的完整需求发给它。样例资料已经包含在里面，Agent 会创建需要的文件。

把这个文件夹当成一张工作台，资料、程序和使用说明都放在一起。有现成资料时，可以把文件放进去让 Agent 先查看；这次直接用下面的虚构资料。

直接复制这段需求

展开完整需求 · 可直接复制给 Agent
我要准备家长会材料。手头有成绩、课堂表现和家访记录，
想给每个学生准备一页，方便打印给家长看。

先用下面三个学生的虚构资料试一下。

成绩（前面是期中，后面是期末）：
张三，学号 S001：语文 80 → 85，数学 70 → 90。
李四，学号 S002：语文 88 → 90，数学 92 → 86。
王五，学号 S003：语文 75 → 82，数学 80 → 78。

课堂表现：
张三：课堂上经常主动举手。作业中偶尔漏写步骤。
李四：作业完成稳定。小组讨论中发言较少。
王五：愿意帮助同学。最近两次作业提交较晚。

家访记录：
张三：家长反映最近开始主动安排作业时间。
李四：与家长约定每周一起回顾一次错题。
王五：还没有家访记录。

每个人的材料里，要有姓名、学号、各科成绩、
提高或下降了多少分，再加上他的课堂表现和家访记录。
不要把不同学生的资料放错；没记录就写“暂无记录”，不要编。

我希望在电脑上就能完成，操作简单一些。
这份样例打印成三页，每页一个学生，按 A4 纸排好。

下次资料更新，我还想继续用。
请把样例资料和页面都保存在当前文件夹，
资料用什么格式，你来安排，告诉我以后怎么换成新的。
请优先用电脑现有的软件就能打开和使用的方式，不用联网。
原始资料保留，生成的材料另外保存。

做好后告诉我打开哪个文件、怎样生成和打印，
再留一份简单的使用说明。
你能试的部分先试一下，告诉我哪些试过了、哪些还没试。

打开结果，核对几处

Agent 可以把这个需要做成一个本地网页。做完后，按照它给出的说明打开结果，载入资料并生成情况卡。它也可能采用其他方式；具体怎么用，以交付的文件和说明为准。

如果还不清楚，可以直接问：“文件夹里有好几个文件，我应该先打开哪个？带我生成一次。”

先看是否有 3 个学生，再核对：

  • 张三数学从 70 分到 90 分，显示提高 20 分。
  • 李四数学从 92 分到 86 分，显示下降 6 分；课堂表现和家访记录对应的是李四。
  • 王五没有家访记录，对应位置显示“暂无记录”。

再点打印按钮，看看预览是否是 3 页、每页一个学生，内容有没有被截掉。浏览器的打印窗口也可以选择保存为 PDF。

本分享包已经附带一份学生情况卡演示。打开就能看到内置的三个学生，也可以选择自己的样例文件重新生成。它是一种实现方式，Agent 为你生成的文件名和页面样式可能不同。

如果打不开、按钮没反应，把发生的情况和截图交给 Agent：

我按说明打开了页面，浏览器里是空白。截图在这里，帮我检查一下。

资料已经放好了，点生成按钮没有反应。我用的是这些资料，请检查一下。

改一点，再用一次

换一个分数，看结果是否跟着变

继续告诉 Agent：

把样例中张三的数学期末成绩从 90 改成 95，其他内容不动。我重新生成一次看看。

按照页面的用法重新载入资料、生成情况卡。张三应显示提高 25 分，其他学生的内容不变。如果还是 90 分，就把这个现象告诉 Agent。

这时可以看到：改动的是资料，原来的页面还能继续处理，结果也跟着改变。

加一个自己用得上的功能

加一个搜索框，输入姓名或学号，就能找到对应学生的情况卡。

做好后，试着搜索“张三”和“S002”，再清空搜索，看看能否回到全部学生。也检查一下分数和打印是否仍然正确。

以后遇到新需要，再继续说：

家访记录留着我自己看。加个开关，打印给家长时可以隐藏这一栏。

有个学生的记录很长，打印时被截掉了。内容长的时候，让它接到下一页。

每次围绕一个具体问题修改，再用资料试一次。反馈时说清楚“我做了什么、实际出现什么、原本希望看到什么”，比只说“再改改”更容易找到问题。

下次怎么继续用

按照使用说明更换资料，再打开原来的页面生成。如果新资料的格式变了，就交给 Agent 检查怎样读取；需要增加功能时，再让它修改这个项目。

让它把操作步骤更新到使用说明里，下次不用翻聊天记录找用法。
