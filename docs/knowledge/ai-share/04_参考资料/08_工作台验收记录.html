哪些结论还不能替它下

  • 改价前的整页 HTML 工作台截图尚未记录；现有改价后截图不能代替完整的前后取证。
  • 界面里另外两款仍为 v1，不等于已经提供了这两款改价前后的文件哈希报告。若要严格证明文件未变，需在同一轮测试中记录并对比。
  • 第 3 步已经有资料表，独立运行统一生成入口后的逐款核对记录仍待补。
  • 已有自动导出文件，不等于系统手动打印对话框也已经逐项验证。
  • 工具说明要求导出失败时保留旧文件，但本页没有附上 HTML 版故障注入的完整记录，不能据此宣称所有失败路径都已通过。
  • 包内有 macOS、Windows 启动脚本；现有记录不能替代每台电脑的环境检查与跨平台实测。
  • 本地保存价格触发更新与钉钉自动同步不是一回事。后者尚未实现。

在自己的电脑上怎么验

第一次从零做海报，只需检查一张页面能打开，再改一处文字并核对。以下检查留到你决定运行完整工作台时再做：

  1. 完整解压工具包，按使用说明检查环境，启动工作台。
  2. 先把小野 500 设为 999，等输出成功。记录三款价格、版本与更新时间；需要严格核验时，让 Agent 记录三款 HTML、PDF、PNG 的文件哈希。
  3. 只把小野 500 改为 899，点保存后不再发送生成指令。
  4. 等成功后，分别打开新的 HTML、PDF、PNG，确认都是 899；再检查另外两款价格、版本、时间，必要时对比文件哈希。
  5. 关闭服务并重新打开，确认资料和文件仍在。若失败，保留报错和截图，先排查，不把输入框的值当作完成依据。

不要为了贴合教程把版本号重置成截图中的数字，也不要在共享钉钉教学表中做破坏性测试。
