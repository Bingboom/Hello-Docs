# 跟着小林做一次：露营产品海报

小林要给周末露营市集准备三款产品海报。同事给了参数和介绍，又提醒他活动价可能会改。小林想做一个小工具：资料填一次，海报能生成，以后改价也能更新。

这页是动手练习。先从空文件夹做起，不需要先下载现成程序。产品型号和参数均为教学虚构。

### 在一个空文件夹里开始

用已经安装并登录的 Codex 或 Claude Code 打开一个空文件夹，把下面的要求交给它。需要的文件和程序让 Agent 创建，小林负责给资料、看效果。

### 直接复制这段需求

> 我不懂编程，请带我做一个露营产品海报工具，每次只做一个能看到结果的小步骤。先检查电脑环境，需要安装软件时说明用途，等我确认。先做一张海报给我看，不要直接做完整系统。
>
> 教学虚构资料如下：
> 小野 300，型号 DEMO-300，容量 288 Wh，额定输出 300 W，重量 3.6 kg，价格 599 元，场景是轻装出游。
> 小野 500，型号 DEMO-500，容量 512 Wh，额定输出 500 W，重量 5.2 kg，价格 999 元，场景是周末露营。
> 小野 1000，型号 DEMO-1000，容量 1024 Wh，额定输出 1000 W，重量 9.8 kg，价格 1599 元，场景是多人营地。
>
> 请把参数保存成表格，每款配一句介绍。介绍引用表格里的参数，不要编造。帮我准备同一画风的 Q 版产品插画；如果不能生成图片，告诉我需要提供什么图片。插画不要带价格和参数。
>
> PDF 使用 LaTeX，先完成小野 300 的 A5 单页海报。确认后再做另外两款：三张共享颜色、字体和组件样式，但分别用大图、图文分栏、参数卡片三种排版。原始资料保留，成品另外保存。
>
> 请把结果打开给我看，并说明哪里换资料、下次怎么打开。

### 打开结果，核对几处

第一张出来后，小林打开 PDF，看参数和价格是否正确、文字是否清楚、有没有挤在一起。满意后，他再让 Agent 做另外两张。

三张都做好时，核对小野 500 是 512 Wh、500 W、5.2 kg、999 元；不要把别款的参数填过来。每份 PDF 都应只有一页，排版不同但风格一致。

如果不满意，把真实截图交给 Agent：

> 产品图太小，介绍和价格挤在一起。请把图放大，调整文字间距，其他参数不要改，改完再打开给我看。

你可以在完成后对照 [本案例的三款成品](../05_露营海报/index.html)。参考成品中的小野 500 已经做过下面的改价测试，所以显示 899 元。

## 改一点，再用一次

### 换一个价格，看结果是否跟着变

小林继续说：

> 请做一个简单的本地页面，能看产品资料、修改价格、查看海报。保存后程序自己更新对应海报，不需要我再发“重新生成”。你来运行并打开页面，告诉我怎么关闭。

他在页面上把小野 500 从 999 改成 899，保存后不再发生成指令。等更新完成，打开新 PDF 看价格；另外两款应该不变。

如果没有更新：

> 页面上已经是 899，但 PDF 还是 999。请检查并修好，再陪我测一次。

### 加一个自己用得上的功能

小林先让 Agent 保存一个可用版本，再一次加一个要求：

> 页面上显示每款最后更新时间和是否成功。资料填错了要提示，失败保留上一次成功海报。

> 我想给小野 1000 换一句介绍，其他两款不动。请修改后打开结果让我看。

这里的改造不需要先学代码。说清楚变什么、不变什么，再检查实际成品。

### 下次怎么继续用

小林最后说：

> 把下次怎么打开、怎么换资料、出错时看哪里写成简单说明。不要让我翻聊天记录找用法。

从空文件夹到钉钉附件的完整故事，见 [主稿附录](../00_打开分享.html#s6)。本地更新和云端更新不是一回事；本案例的钉钉持续自动更新尚未完成。
