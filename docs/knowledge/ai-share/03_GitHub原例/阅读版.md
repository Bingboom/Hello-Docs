# 动手小练习：让产品介绍里的价格跟着变

小林已经写好一句产品介绍：

> 小野 500，容量 512 Wh，教学价 999 元。

同事说，价格改成 899。他希望只修改保存价格的地方，重新生成介绍，不用在每句话里找数字。

我们就从这一件小事开始：**生成一句介绍，改一次价格，再检查结果。** 小野 500 和这里的参数、价格均为教学虚构资料。

## 一、把这个小任务交给 Agent

用 Codex 或 Claude Code 打开一个空文件夹，把下面这段话发给它：

> 帮我做一个最小的 Python 小练习。产品名是“小野 500”，容量是 512 Wh，教学价是 999 元，都是教学虚构资料。
>
> 请把名称、容量和价格分别保存，再用它们拼出一句介绍：“小野 500，容量 512 Wh，教学价 999 元。”
>
> 文件命名为 product_intro.py，保存在当前文件夹。先只做这一句，不加界面。检查能否运行；如果缺少 Python，请先说明需要安装什么，等我确认。运行后给我看实际输出，并指出在哪里修改价格。

也可以下载现成的 [练习文件 product_intro.py](product_intro.py){download="product_intro.py"}，放进项目文件夹，让 Agent 打开并运行。[手动运行方法](使用说明.txt) 留着需要时查。

## 二、先运行，看看它写出了什么

配套文件只有下面几行：

```python
product_name = "小野 500"
capacity_wh = 512
price = 999

intro = f"{product_name}，容量 {capacity_wh} Wh，教学价 {price} 元。"
print(intro)
```

现在不用逐个记住符号。先让 Agent 运行，看看结果是不是：

```text
小野 500，容量 512 Wh，教学价 999 元。
```

核对三个地方：名称是小野 500，容量是 512 Wh，价格是 999 元。第一次运行正确了，再往下走。

## 三、只改价格，再运行一次

接着告诉 Agent：

> 把 product_intro.py 中的 price 从 999 改成 899，名称、容量和生成介绍的那一句都不要改。保存后重新运行，给我看输出。

这次只需要改一行：

```python
price = 899
```

重新运行后，应该看到：

```text
小野 500，容量 512 Wh，教学价 899 元。
```

**价格变了，名称和容量没变，这次练习就完成了。** 不必马上增加其他功能。

如果结果没变，把实际输出发给 Agent：

> 我想看到 899，但运行结果还是 999。请检查刚才修改是否保存、运行的是不是这个文件。修正后重新运行，不要直接手写一段输出给我。

这里需要保存并重新运行，文字才会更新；这个小例子不会在后台自动更新。

## 四、刚才发生了什么？这时再认识变量

回头看这一行：

```python
price = 899
```

可以把它读成：“把 899 这个值交给名叫 price 的变量。”程序后面需要价格时，就使用这个名字，而不是到处写死 899。

生成介绍的这一行里，`{price}` 表示在这里填入价格；`{product_name}` 和 `{capacity_wh}` 同样填入名称与容量。引号前的 `f` 告诉 Python 按这种方式填值，最后的 `print` 把生成的文字显示出来。

所以刚才只改了 `price`，重新运行时，介绍里的价格也跟着变了。**句子的写法没变，用来填句子的资料变了。**

想再试一次，可以只修改产品名称，运行后检查：名称有没有换过来，容量和价格是否保持不变。每次只改一处，就容易看清它影响了哪里。

## 五、把这个办法用回海报

一句介绍能这样生成，海报上的名称、参数和价格也可以读取资料来填入。

小练习把三个值写在代码开头。产品多起来后，可以把资料整理成表格，让程序按型号找到对应产品，再把名称、参数和价格放到海报的相应位置。这样，资料和排版就能分开维护。

小林接下来可以说：

> 我想把刚才的办法用到海报里。先只处理小野 500：从产品表读取名称、容量和价格，展示读到的资料与生成的介绍。我确认正确后，再把它们放进海报，保留已经确认的样式。

这一步可以接着 [完整练习：把资料留在项目里](../04_参考资料/01_完整练习.html#s2) 做。先让一句话跟着资料变化，再把同样的思路用到一张海报，不必一开始就搭完整工作台。
