产品介绍小练习

先打开“阅读版.html”，查看说明和预期输出。
本次练习的可运行文件是 product_intro.py，需要 Python 3.6 或更新版本，无第三方依赖。
只需 Python，无需安装额外的库。

可以直接告诉 Agent：
请只运行这个文件夹里的 product_intro.py，让我看到原来的输出。
然后把 price 从 999 改成 899，其他内容不动，保存后重新运行。
如果没有 Python，请先说明安装用途，等我确认。

也可以在本目录的终端运行：
macOS / Linux：python3 product_intro.py
Windows（已安装 Python 启动器）：py product_intro.py

第一次预期输出：小野 500，容量 512 Wh，教学价 999 元。
改价后预期输出：小野 500，容量 512 Wh，教学价 899 元。
改完需保存并重新运行，输出才会更新。
