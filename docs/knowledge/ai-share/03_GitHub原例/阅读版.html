从 the craft of selfteaching 开始：改一句产品介绍

不必先读完整本书，再开始动手。小林已经有了一个具体问题：产品价格变了，介绍里的数字能不能一起变？我们就从这个问题出发，读一点、运行一次、改一点，再看结果。

本页参考李笑来 the craft of selfteaching的“字符串”学习主题，为露营海报另写一份中文练习。不是原书摘录，也不是原书代码的运行记录。三款小野产品均为教学虚构型号。

一、先找到与你的问题有关的一小节

打开 the craft of selfteaching，在目录里找到 字符串，先看“格式化字符串”下的“使用 f-string”。

暂时只需要理解一件事：一句文字里，可以放入变量的值。其他不懂的地方先记下，等练习用到时再问。

小林可以对 Agent 说：

我想让产品介绍里的名称、容量和价格跟着资料变化。请结合这本书的字符串主题，给我一个中文小例子。先只生成一句介绍，不要一开始做完整海报工具。

二、先运行：让程序写出一句介绍

把下面这段交给 Agent，让它保存成 Python 文件并运行。没有 Python 环境时，让它先说明安装用途，不需要为了这一步先安装 Notebook 或画图库。

product_name = "小野 500"
capacity_wh = 512
price = 999

intro = f"{product_name}，容量 {capacity_wh} Wh，教学价 {price} 元。"
print(intro)

这段代码的输出是：

小野 500，容量 512 Wh，教学价 999 元。

前面三行分别保存名称、容量和价格。引号前的 f 表示：把大括号里的变量换成它们当前的值。print 把结果显示出来。

这不是 AI 临时编出参数，而是程序使用你给定的三个值。先核对这句话里的名称和数字，再继续下一步。

三、改一点：只改价格，再运行一次

同事通知小林：活动价改成 899。小林只改 price，不去手动改那句介绍。

product_name = "小野 500"
capacity_wh = 512
price = 899

intro = f"{product_name}，容量 {capacity_wh} Wh，教学价 {price} 元。"
print(intro)

重新运行后的输出：

小野 500，容量 512 Wh，教学价 899 元。

小林核对：价格变成 899，产品名和容量不变。再试着把产品名改成“小野 300”、容量改成 288、价格改成 599，看看是否得到对应的句子。

注意：这里需要重新运行程序，才会生成新文字；并没有开启后台自动更新。已经生成的 intro 不会因为之后修改 price 就自己变化，需要重新执行生成 intro 的那一行。

四、遇到问题：让 Agent 对着结果解释

小林不必背语法，可以带着具体问题继续问：

为什么引号前面要加 f？如果不加会出现什么？请运行给我看，再解释区别。

我改了价格，输出却没变。请检查是不是没保存、运行了旧文件，或者没有重新生成 intro。不要直接把输出文字改成 899。

请在测试副本里把 price 写成另一个不存在的变量名，给我看错误，并教我怎样从错误里定位问题。不要破坏原来的可用文件。

每次只试一个变化。看到结果，再回到书里的对应小节，概念就有了具体参照。

五、接回海报：从一句话走向一张表

刚才的名称、容量和价格写在代码里。下一步可以让 Agent 把它们改为从产品表读取：按型号找到一行，取出参数，生成介绍，再交给排版程序。

请保留刚才生成介绍的逻辑，改成从产品表读取资料。先只处理小野 500，把读到的参数和生成的文字展示出来。缺少参数时提示我，不要猜。确认正确后再接到海报里。

这一步还没有实现 CSV 读取、PDF 排版、文件监听或钉钉上传，不要把一句介绍的小练习说成完整系统。回到 主稿 和 露营海报练习，再按需要逐步增加功能。

主案例内容表中的 {{product_name}} 是海报工具约定的模板标记；这里 f-string 的 {product_name} 是 Python 写法。它们都用于填入变量，但不能直接混用，读取和替换方式要由程序明确处理。
